Como atualizar o histórico de vendas?

Importe o JSON de faturamento atualizado que você guardou no computador. O arquivo deve ser uma lista de registros no formato [mês, cliente, SKU, produto, quantidade, valor, marca], como no dashboard anterior. Você pode selecionar novamente outro arquivo para atualizar a análise. Por segurança, a base não fica salva no navegador: ao atualizar a página, será necessário importar novamente.
